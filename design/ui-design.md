# UI 界面设计文档

> 视觉参考：AnotherRedisDesktopManager（信息密度与布局）、RESP.app（现代感与配色）
> 实现框架：Compose Multiplatform + Material3（项目已有 `Theme.kt`）

---

## 1. 整体布局

主窗口采用经典三栏结构（左栏可拖拽调宽，已有实现基础）：

```
┌────────────────────────────────────────────────────────────────────────┐
│  标题栏 / 菜单栏（macOS 融入系统菜单栏）                                     │
├──────────────┬─┬───────────────────────────────────────────────────────┤
│              │ │  Tab 栏：[dev-redis ▾] [prod-redis ▾] [+]              │
│  连接面板     │ ├─────────────────────┬─────────────────────────────────┤
│              │ │                     │                                 │
│  · 连接搜索框 │拖│   Key 列表面板       │       值查看/编辑面板             │
│  · 连接树     │拽│                     │                                 │
│    ├ 生产环境 │条│  · 搜索框 + 刷新      │   · Key 元信息(类型/TTL)         │
│    ├ 测试环境 │  │  · 树形/平铺切换     │   · 类型化值编辑器               │
│    └ dev     │  │  · Key 列表(SCAN)   │   · 格式化选择器                │
│              │ │                     │   · 保存/删除/复制按钮            │
│  [+ 新建连接] │ │                     │                                 │
├──────────────┴─┴─────────────────────┴─────────────────────────────────┤
│  状态栏：已连接 127.0.0.1:6379 · db0 · 已加载 1,024/35,210 keys · 只读     │
└────────────────────────────────────────────────────────────────────────┘
```

### 分区说明

| 区域 | 宽度 | 说明 |
|------|------|------|
| 连接面板 | 240~400dp，默认 300dp | 未连接时展示全部连接；可分组折叠 |
| 拖拽分隔条 | 4dp | 鼠标悬停变为 ↔ 光标（已实现） |
| Key 列表面板 | 320~480dp | 与值面板之间也设可拖拽分隔条 |
| 值查看面板 | 弹性填充 | 无选中 Key 时显示空状态引导 |

## 2. 连接面板（Left）

```
┌──────────────────────┐
│ 🔍 搜索连接...         │
├──────────────────────┤
│ ▾ 📁 生产环境          │
│   🟢 prod-cache       │  ← 绿点=已连接
│   ⚪ prod-session     │
│ ▸ 📁 测试环境          │
│ ▾ 🔗 本地开发          │
│   🟢 dev-redis        │
│   ⚪ local-sentinel   │
├──────────────────────┤
│ [ ＋ 新建连接 ]        │
└──────────────────────┘
```

- 连接项：颜色标签条 + 状态圆点 + 名称（双击连接，右键弹出菜单）
- 已连接的连接下方展开 **DB 列表**（db0~db15，显示 key 数），点击切换 DB
- 右键菜单：编辑 / 复制 / 删除 / 打开控制台 / 服务器信息

---

## 3. 工作区 Tab 栏

- 每个连接的每个"页面"都是一个 Tab：`Key 浏览` / `控制台` / `服务器信息`
- Tab 标题：`连接名 — 页面类型`，可中键点击或 × 关闭
- Tab 右键菜单：关闭 / 关闭其他 / 关闭右侧
- 支持拖拽排序、鼠标滚轮切换

## 4. Key 浏览页（核心页面）

### 4.1 布局

左右两栏（各自可滚动，中间拖拽条）：

```
┌─────────────────────────┬──────────────────────────────────────────┐
│ [*user*        🔍] [刷新]│  user:1001:profile                       │
│ 树形 | 平铺   已加载 1024 │  ┌────────────────────────────────────┐  │
├─────────────────────────┤  │ 类型: Hash    TTL: 3600s           │  │
│ ▾ user (512)            │  │ 内存: 2.1 KB   [改TTL] [删除] [刷新] │  │
│   ▾ 1001 (3)            │  └────────────────────────────────────┘  │
│      📄 profile          │  ┌────────────────────────────────────┐  │
│      📄 settings         │  │ 格式化: [Auto ▾]     [+ 新增字段]   │  │
│   ▸ 1002 (2)            │  ├──────────┬─────────────────────────┤  │
│ ▾ order (128)           │  │ field    │ value                   │  │
│   📄 pending:123        │  │ name     │ "张三"             [✏️][🗑]│  │
│   📄 done:456           │  │ avatar   │ "https://..."      [✏️][🗑]│  │
│ ...滚动加载更多...        │  └──────────┴─────────────────────────┘  │
└─────────────────────────┴──────────────────────────────────────────┘
```

### 4.2 Key 列表交互

- **滚动到底自动加载**下一批（SCAN cursor），底部显示加载指示器
- 类型图标区分：String `📄` / Hash `#️⃣` / List `☰` / Set `{}` / ZSet `⚖️` / Stream `〰️`（用 Material Icons 实现）
- 选中高亮；支持 `Cmd+点击` 多选、`Shift+点击` 范围选
- 右键菜单：复制 Key / 重命名 / 删除 / 查看内存 / 导出
- 方向键上下移动选中项

### 4.3 值面板（按类型切换）

| 类型 | 展示形态 |
|------|----------|
| String | 多行文本编辑框 + "JSON 格式化"按钮 + 保存按钮 |
| Hash | Field/Value 双列表格，单元格双击行内编辑 |
| List | 单列表格，头部 [LPUSH] 尾部 [RPUSH] 按钮 |
| Set | 单列表格 + 成员搜索框 |
| ZSet | Member/Score 双列表格，按 score 排序，可切换 |
| Stream | 消息卡片流（ID + 字段表格），右侧 Group/Consumer 面板 |

- 长值截断：超过 10KB 显示前段 + `[加载更多]`
- 二进制值：自动切换 Hex 视图，提供"下载为文件"

## 5. 新建连接弹窗

在现有 `NewConnectionDialog` 基础上扩展为分节表单：

```
┌─────────────────────────────────────────┐
│  新建连接                          [✕]  │
├─────────────────────────────────────────┤
│  连接名称  [_______________________]    │
│                                         │
│  ── 基础 ──────────────────────────     │
│  Host     [127.0.0.1   ]  Port [6379]  │
│  用户名   [________] 密码 [________]    │
│  默认 DB  [0 ▾]   分隔符 [:]            │
│                                         │
│  ▸ SSH 隧道（点击展开）                  │
│  ▸ SSL/TLS（点击展开）                  │
│  ▸ 高级（超时/只读/自动重连）             │
│                                         │
│       [ 测试连接 ]   [ 取消 ] [ 确定 ]   │
└─────────────────────────────────────────┘
```

- 折叠区默认收起，保持弹窗简洁
- **[测试连接]**：异步测试并反馈成功/失败原因（Loading 态）
- 校验：名称必填、Host 格式、端口范围

## 8. 补充：弹窗、菜单与设置页

### 8.1 新建 Key 弹窗

```
┌────────────────────────────────────────┐
│  新建 Key                        [✕]  │
├────────────────────────────────────────┤
│  类型: [String ▾]                      │
│  Key:  [_______________________]       │
│  TTL:  [ -1 (永久) ] 秒                │
│                                        │
│  ── 按类型切换的值表单 ──              │
│  String: 值输入框(多行)                │
│  Hash:   field/value 行编辑器(可加行)  │
│  List:   成员行编辑器                  │
│  Set:    成员行编辑器                  │
│  ZSet:   member/score 行编辑器         │
│                                        │
│          [ 取消 ]   [ 创建 ]           │
└────────────────────────────────────────┘
```

- 类型切换时值表单动态替换；Key 重复时提示并询问是否覆盖

各类型值表单明细：

| 类型 | 表单内容 |
|------|----------|
| String | 多行文本输入框（自动识别 JSON，可格式化） |
| Hash | field/value 行编辑器，可增删行 |
| List | 插入位置选择（LPUSH/RPUSH）+ 成员行编辑器 |
| Set | 成员行编辑器（提示自动去重） |
| ZSet | member/score 双列行编辑器 |

### 8.2 右键菜单清单

| 目标 | 菜单项 |
|------|--------|
| 连接项 | 连接/断开 · 编辑 · 复制 · 删除 · 打开控制台 · 服务器信息 |
| Key 树目录 | 批量删除 · 导出 · 复制前缀 |
| Key 项 | 复制 Key · 复制值 · 重命名 · 删除 · 查看内存占用 · 导出 |
| Tab | 关闭 · 关闭其他 · 关闭右侧 |

### 8.3 设置页

以 Tab 形式打开的全局设置，分区：

- **外观**：主题（浅色/深色/跟随系统）、字体族、字号
- **浏览**：每批加载数量、值截断阈值、默认视图（树形/平铺）
- **安全**：只读模式全局开关、密码加密存储开关
- **通用**：语言、快捷键自定义（P2）

左侧分区导航点击滚动定位；设置项本地 JSON 持久化（与连接配置同目录）。

### 8.4 Toast 与确认弹窗

- Toast：右下角堆叠，3 秒自动消失；成功绿/错误红/警告橙，错误型可展开详情并复制
- 确认弹窗：DEL 等危险操作二次确认；FLUSHDB 需输入 DB 名才可启用确认按钮

## 9. 设计规范

### 9.1 配色

| 角色 | 浅色 | 深色 |
|------|------|------|
| 主色（Redis 品牌红） | `#DC382C` | `#E05B4B` |
| 背景 | `#FAFAFA` | `#1E1F22` |
| 面板背景 | `#FFFFFF` | `#26272B` |
| 正文 | `#212121` | `#E4E4E7` |
| 次要文字 | `#757575` | `#9E9EA3` |
| 选中/悬停 | 主色 8% 透明度 | 主色 12% 透明度 |
| 成功/已连接 | `#22A45D` | `#34C772` |
| 错误/失败 | `#D32F2F` | `#F06A6A` |

### 9.2 类型图标色

String 蓝 `#3B82F6` · Hash 橙 `#F59E0B` · List 紫 `#8B5CF6` · Set 绿 `#10B981` · ZSet 粉 `#EC4899` · Stream 青 `#06B6D4`

### 9.3 排版与间距

- 字号：正文 13sp、表格 12sp、标题 14~16sp；等宽字体用于值/控制台
- 间距：4dp 基准（已有 `AppDimens`），内边距 8/12/16dp
- 圆角：按钮 8dp、卡片 8dp、弹窗 12dp
- 行高：列表行 32dp，表格行 28dp（保证信息密度）

## 10. 空状态与异常态

| 场景 | 表现 |
|------|------|
| 未连接 | 右侧显示 Logo + "从左侧选择一个连接开始" |
| 连接失败 | Toast + 连接标红，展示错误详情可复制 |
| Key 为空 | 列表区显示"当前 DB 没有 Key，点击新建" |
| 加载中 | 骨架屏 / 底部 Loading 条 |
| 大 Key 超时 | 警告条 + "重试 / 取消"按钮 |
| 危险操作（DEL/FLUSHDB） | 确认弹窗，FLUSHDB 需输入 DB 名确认 |
