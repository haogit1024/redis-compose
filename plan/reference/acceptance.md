# 验收与自检清单

> 每个阶段都先跑“通用检查”，再跑阶段文档里的“阶段专属验收”。Agent 无法查看真实渲染时，也必须逐条对照代码与设计稿做静态检查。

---

## 1. 构建与静态检查

```bash
./gradlew ktlintCheck
./gradlew :app:jvmTest
./gradlew build
./gradlew :desktopApp:run
```

必须全部通过。`run` 至少在目标平台启动一次并手动点击主要路径；不能只依赖编译。

---

## 2. 通用视觉检查

在以下窗口尺寸检查（可用 `WindowState` 临时调整，或拖动窗口）：

| 尺寸 | 关注点 |
| --- | --- |
| 1440 × 900 | 设计基准；三栏比例、图表、空状态 |
| 1200 × 800 | 最小可用桌面宽度；Key 面板与值面板不挤压 |
| 1120 × 720 | 最小窗口；侧栏、顶栏、按钮不溢出 |

两个主题都要看：

- 深色（默认）
- 浅色
- 至少一种非 Iris 强调色（设置页切换后）

检查项：

- [ ] 背景不是纯黑 / 纯白；层级由 surface 递进。
- [ ] 边框不过多；没有“每块都描边”的旧式面板感。
- [ ] 文本对比度足够；textTertiary 不用于关键信息。
- [ ] 所有圆角/间距来自 token；没有 1px 乱入或 7dp 魔法值。
- [ ] 按钮 hover / active / disabled 三种状态可见。
- [ ] 输入框 focus 环可见，且不改变布局尺寸。
- [ ] 图标粗细、尺寸一致（16dp 基准）。
- [ ] 长 Key、长 Host、长命令不会撑破布局（省略号/换行策略明确）。
- [ ] 滚动条细且不遮挡内容。
- [ ] 空状态有标题、说明、下一步操作。

### 2.1 页面级对照

- 键浏览器：`design/workspace.html`（默认 JSON 视图、Hash 视图）；
- 控制台：`design/console.html`；
- 洞察：`design/insights.html`；
- 连接库：`design/connections.html`（含侧滑）；
- 设置：`design/settings.html`；
- 总览：`design/index.html`。

允许有差异的地方：

- 字体渲染与 Material 图标形状；
- 设计稿中的 24h 历史图表 → 实现为会话内采样；
- 设计稿中的审计活动表 → 实现为最近连接；
- 设计稿中的新建连接“导入配置” → v1 可不实现。

不允许的差异：

- 结构顺序、层级关系；
- 颜色语义（成功/警告/危险/类型色）；
- 主操作位置与视觉权重；
- 空/错/只读状态缺失。

## 3. 通用交互检查

- [ ] 窗口最小尺寸下无水平滚动条。
- [ ] 左右面板分隔线可拖拽时，拖动范围符合 token；内容不抖。
- [ ] Tab 键焦点顺序合理；Esc 关闭最上层弹层。
- [ ] 弹层打开时背景遮罩可见；点击遮罩关闭（命令面板/对话框/sheet）。
- [ ] 所有 toast 自动消失，不遮挡底部状态栏。
- [ ] 复制操作有 toast 反馈。
- [ ] 保存/删除按钮有 disabled 状态（只读、无选择、无修改）。
- [ ] 错误不吞掉：错误状态有文案，可重试。
- [ ] 断网/Redis 停止时应用不崩溃，连接状态显示错误。

---

## 4. 数据正确性

- [ ] 所有 Redis 调用通过 `RedisGateway`，没有 feature 直接 import Jedis。
- [ ] 同一连接的 Jedis 调用串行化；主线程无阻塞。
- [ ] Key 列表使用 SCAN，不是 `KEYS *`。
- [ ] 删除 Key 前有确认（除非设置关闭）。
- [ ] 只读模式拦截所有写操作（SET/HSET/DEL/EXPIRE/FLUSHDB 等），包括控制台。
- [ ] TTL -1 显示“永久”，0 表示“即将过期/已过期”语义正确。
- [ ] 内存/编码为 null 时有占位而不是崩溃。
- [ ] 非 UTF-8 值显示 HEX，不出现乱码替换符。
- [ ] 密码不明文出现在 UI、日志、异常信息中。
- [ ] 关闭会话后，gateway 关闭，相关轮询停止。

---

## 5. 性能

- [ ] 10,000+ Key 的树/列表滚动流畅；使用 LazyColumn，不一次性组合全部行。
- [ ] 输入搜索不每个按键都发 SCAN；至少 200ms debounce 或显式回车。
- [ ] 刷新/切换 Key 时取消旧请求，旧结果不覆盖新结果。
- [ ] 值编辑器对 > 1MB 的文本有截断提示，不冻结 UI。
- [ ] 洞察页离开后停止轮询；重新进入可恢复。
- [ ] 窗口缩放时图表自适应，不触发无限重组。

---

## 6. 代码质量

- [ ] 没有 `com.czh.redis` 旧包引用（Phase 0 后）。
- [ ] 没有把旧组件复制进新包。
- [ ] 没有 `TODO` 无阶段标记；允许 `TODO(phase-8): ...`。
- [ ] 公开类型/函数有清晰命名；不存在 `Utils` 巨类。
- [ ] 没有在 feature 中硬编码颜色/字体/间距。
- [ ] 没有未使用的依赖；`material-icons-extended` 只在 Phase 1 引入。
- [ ] ktlint 无警告/错误。
- [ ] 单元测试覆盖新增纯逻辑。

## 7. 阶段专属验收模板

每个阶段文档会提供类似：

```text
Phase N 验收：
1. ./gradlew :app:jvmTest
2. ./gradlew :desktopApp:run
3. 截图检查 <页面> 在 dark/light 下与 design/... 对齐
4. 手动路径：...
5. 失败路径：...
```

Agent 必须把结果写入 `plan/STATUS.md`。未通过的项不能标记阶段完成。
