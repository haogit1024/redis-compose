  - `com.czh.redis` 旧包残留（包括注释、import、package）；
  - 未使用的旧组件/工具/测试；

- 检查 `gradle/libs.versions.toml` 无未使用条目。

### 2.3 文档

## 5. 性能与稳定性

- 10,000 Key：
  - 首次加载/滚动/搜索/类型筛选；
  - 不一次性请求所有 TYPE/TTL；
  - 切换 Key 不卡顿。
- 1MB+ String：
  - 展示截断，不冻结；
  - 保存操作有 loading，不重复点击。
- 10,000 行 List/ZSet：
  - 虚拟化，不全部组合；
  - 筛选/滚动可用。
- 控制台大输出：
  - 截断/限制条目；
  - 自动滚动不抢用户滚动。
- 洞察：
  - 5 秒采样，样本上限 720；
  - 离开页面停止；
  - 重进不重复启动 job。
- 连接异常：
  - Redis 停止、认证失败、超时、SSH 失败；
  - 应用不崩溃，错误可读，可重试。
- 内存：
  - 关闭 tab/session 后 scope 取消；
  - 不残留 gateway/轮询。
- 主线程无阻塞 IO（代码搜索 `Dispatchers.IO`、`runBlocking`）。

## 6. 可访问性

- 所有图标按钮有 contentDescription/tooltip。
- 对比度：正文 text/textSecondary 在两种主题下可读；状态色不作为唯一信息。
- 焦点：Tab 可到主要操作；焦点环可见；Esc 关闭顶层。
- 输入框有标签/placeholder；错误可被读到（文本 + 颜色）。
- 文本可选择复制（Key、值、日志、错误）。
- 动画不阻塞操作；不实现无限动画干扰阅读。

## 7. 测试

### 7.1 单元测试

确认 Phase 2/5 的测试仍然通过；补充：

- 设置序列化/默认值；
- 快捷键判定（N/R 在输入焦点时的行为，如果抽成纯函数）；
- 只读命令判定表；
- 命令解析（引号/空格）；
- 指标区间过滤；
- 连接校验。

### 7.2 手动回归

建立一份简短的 `plan/QA-CHECKLIST.md`（本阶段创建），列出最终验收路径、测试数据准备（建议 docker Redis 7.4）、结果。

- Redis 容器示例：
  ```bash
  docker run --rm -p 6379:6379 redis:7.4
  ```
- 准备测试数据（可选脚本）：
  - String（普通/JSON/超长/非 UTF-8）
  - Hash / List / Set / ZSet / Stream
  - TTL 永久/短 TTL
  - 空 DB / 大量 Key

### 7.3 构建产物

```bash
./gradlew clean build
./gradlew :desktopApp:packageDistributionForCurrentOS
```

- 确认打包任务存在且成功；若当前配置未启用，至少确保 `run` 正常并记录原因。
- 检查包名/版本/应用名。
